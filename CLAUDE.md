# Правила работы с репозиторием

- Каждое изменение мода по запросу — новая версия (0.1.0 → 0.1.1 → 0.1.2 …):
  1. поднять `mod_version` в `gradle.properties`;
  2. добавить раздел в `CHANGELOG.md` (формат `## [X.Y.Z] — дата`);
  3. закоммитить и запушить в `main`. Workflow `build.yml` увидит новую `mod_version`,
     сам создаст тег `vX.Y.Z` и релиз с jar (пушить теги из облачной среды нельзя).
     `release.yml` — ручная пересборка релиза для старой версии (тег + SHA коммита).
- Minecraft 1.21.1, Fabric, Yarn-маппинги, Java 21. Собрать локально в облачной среде
  нельзя (Fabric maven закрыт) — проверка компиляции идёт через GitHub Actions.
- Тексты для игрока — через переводы `assets/diktatura/lang/ru_ru.json` и `en_us.json`.
